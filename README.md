# RISC-V-single-cycle-without-pipelined-
Designed and implemented a 32-bit RISC-V single-cycle processor based on the RV32I instruction set.Supports R-type, I-type, S-type, B-type, load/store, and jump (JAL) instructions with correct control flow and  have given instructions in the memory to cross verify every output.
